# Presentación

`Proyecto_DemandaBicicletas.pptx` contiene 12 diapositivas editables con decisión de negocio, descripción de datos, análisis exploratorio, inferencia, esquema SQL/BI, comparación de modelos, resultados, IA generativa, límites y referencias.

Para recrear el archivo desde una clonación, ejecutar `node scripts/make_presentation.mjs` desde la raíz del repositorio, con el módulo Artifact Tool disponible en el entorno Codex. Las rutas del script se calculan desde su ubicación dentro del repositorio.
